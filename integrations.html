Remote service pattern

Configured process and credential scope.

In production remote mode, the MCP process binds tenant scope through trusted configuration and uses a configured bearer token for the remote HTTP service. The caller cannot supply a tenant tool argument. No MCP export tool exists; export and verification use separate HTTP/OpenAPI or CLI surfaces.

OriginExplicit base URL; redirect and cross-origin behavior remains contained.
TenantProcess-configured tenant; mismatched requested scope is rejected where applicable.
ResultStructured `ok`, decision-evidence or error outcome; protocol errors remain distinct.
CallerMust stop or continue the framework action based on the result.
