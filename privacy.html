This repository edition of the Signet7 project site is static. It contains no waitlist form, account login, analytics script, advertising tracker, or direct browser-to-Signet7 data-submission workflow.

This is a status statement, not a final commercial privacy policy. A deployed service, customer pilot, hosted demo, analytics tool, support channel, or lead form requires an approved data map, notice, lawful basis, vendor review, retention/deletion process, and responsible owner before collection begins.

What the static files do

  • Load local HTML, CSS, favicon, and logo assets from this repository.
  • Link to repository documentation and locally stored artifacts.
  • Use no embedded third-party font, JavaScript, analytics, chat, or form provider.

Hosting metadata

A hosting provider may independently process ordinary request metadata such as IP address, user agent, requested path, timestamps, and security logs. That behavior depends on the selected host and deployment configuration; it is not defined by these static files. Any public deployment must identify the host and accurately document that processing.

Application data warning

The application API can process identifying metadata supplied in decision records. The retired waitlist collector is not exposed. Deployers must not process personal data until privacy, security, access, retention, deletion, and incident obligations are approved and operational.

Legal and operating status

Signet7 is documented here as a pre-formation project with release-candidate software version 0.2.0rc1. Repository publication does not establish a legal entity, data controller, processor relationship, customer contract, or authority to make privacy commitments. Effective legal records and approved service terms must identify the responsible party before external collection or service delivery.

Repository boundary

Do not place customer data, leads, credentials, private keys, legal instruments, signatures, private contact information, or person-specific economic records in the shared product repository. See the trust and claims register and legal implementation status.
