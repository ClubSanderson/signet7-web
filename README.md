## Reasoning

The public repository now consumes the email-first, claim-controlled website source from the primary Signet7 repository and makes the approved circular seal the persistent visual identifier. This keeps the website visually unified without copying private business material.

## Final content

This repository is the sanitized GitHub Pages export of the public website maintained under `10-product/www/` in the private `ClubSanderson/Signet7` source-of-truth repository.

### Public pages

- `index.html` — category promise and current evidence model
- `product.html` — email trust product layers
- `trust.html` — boundaries, evidence, and trust model
- `integrations.html` — provider and enterprise integration direction
- `brand.html` — public logo, color, voice, and boilerplates
- `about.html` — team and mission
- `privacy.html` — privacy and legal status
- `docs.html` — public current-state references

### Brand requirements

- Use `assets/signet7-logo.png` as the canonical circular mark.
- Keep the primary promise: **Proof for the email decisions that matter.**
- Present the email trust platform first, VSN second, and AI/workflow integrations as supporting consumers.
- Do not expose private strategy, compensation, pricing, investor pipeline, legal drafts, or team-only data.
- Do not claim certification, universal provider support, production assurance, or legal identity proof.

### Deployment

GitHub Pages publishes the repository root to `signet7.io`. The primary repository remains the content source of truth; this repository should receive sanitized, reviewable exports only.
